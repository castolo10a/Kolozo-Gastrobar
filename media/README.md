# Carpeta de fotos y videos nuevos

Deja aquí los archivos **originales** (con la mejor calidad que tengas). No se suben a git:
cuando estén listos, se optimizan (WebP para fotos, MP4 comprimido para videos) y se
mueven a `src/assets/`.

## Qué buscamos

Fotos y videos que muestren **la experiencia**, no solo el plato:

- Gente disfrutando: brindis, risas, mesas llenas, la barra en acción.
- El lugar de noche: luces, neón, plantas, la terraza.
- Platos **en su contexto**: sobre la mesa, con manos, bebidas y el ambiente detrás.
- Evitar: flyers con texto, fotos de plato con fondo plano, capturas de pantalla, fotos borrosas.

Calidad mínima: fotos de **1600 px** de ancho o más. Videos horizontales, **10 a 20 s**, sin texto encima.

## Nombres de archivo (para saber dónde va cada uno)

| Archivo | Dónde se usa | Formato ideal |
|---|---|---|
| `hero.mp4` | Fondo de la portada (video en bucle, sin sonido) | Horizontal, de noche, ambiente con gente |
| `hero.jpg` | Imagen de portada (y respaldo del video) | Horizontal |
| `nosotros.jpg` | Sección Nosotros | Horizontal, interior o terraza |
| `salvaje.jpg` | Sección Hamburguesa Salvaje | Cuadrada o vertical |
| `menu-carta.jpg` | Tarjeta "La carta" | Vertical |
| `menu-cocteleria.jpg` | Tarjeta "Coctelería" | Vertical |
| `menu-almuerzos.jpg` | Tarjeta "Almuerzos" | Vertical |
| `eventos-celebraciones.jpg` | Tarjeta "Celebraciones en grupo" | Horizontal |
| `eventos-pareja.jpg` | Tarjeta "Planes en pareja" | Horizontal |
| `galeria-01.jpg` … `galeria-12.jpg` | Galería | Cualquiera (se recorta en cuadrado) |

Si un archivo no aparece, se mantiene la imagen actual en ese lugar.
